# Customer Care Analytics Dashboard

## Project Overview
An independent portfolio project analysing customer care operations using Tableau. The dashboard provides insights into contact volumes, response SLA compliance, resolution performance, channel distribution and customer satisfaction.

**Note:** This project uses synthetic data and is not affiliated with or endorsed by Apple.

## Tools Used
- Tableau Desktop
- Tableau Prep
- CSV
- Data Cleaning and Data Visualisation

## Dataset
- 22,000 customer care interactions
- 22 months of activity (January 2025 – October 2026)
- Four contact channels: Phone, Chat, Email and Messaging

## Key Performance Indicators
- Total Contacts
- Response SLA Compliance
- Resolution SLA Compliance
- Average Resolution Time
- Average Customer Satisfaction (CSAT)

## Dashboard Insights
- Monthly contact volume trends
- Contact channel distribution
- Response SLA performance by channel
- Customer satisfaction by channel
- Most common customer issues
